## 项目背景

### 项目简介
- **项目名称**: 合同预审看板系统
- **技术栈**: 
  - 前端: React + TypeScript + Ant Design
  - 后端: Python FastAPI + PostgreSQL + Redis
  - 部署: Docker + Nginx
- **域名**: https://chenmin0922.online

### 为什么选择钉钉登录?

1. ✅ **企业内部应用**: 团队已使用钉钉办公,无需额外账号体系
2. ✅ **安全可靠**: 基于OAuth 2.0,由钉钉保障安全性
3. ✅ **用户体验好**: 扫码登录,无需记忆密码
4. ✅ **自动同步**: 可获取用户信息和组织架构

### 核心流程

```
用户访问系统 → 自动跳转钉钉授权页 → 扫码授权 → 
回调获取code → 后端换取token → 获取用户信息 → 
同步到数据库 → 生成JWT → 登录成功
```

### 2. Node.js 实现示例

```javascript
// routes/auth.js
const express = require('express');
const axios = require('axios');
const router = express.Router();

const APP_KEY = process.env.DINGTALK_APP_KEY;
const APP_SECRET = process.env.DINGTALK_APP_SECRET;

// 钉钉登录接口
router.post('/dingtalk', async (req, res) => {
  try {
    const { code } = req.body;
    
    if (!code) {
      return res.status(400).json({ 
        success: false, 
        message: '缺少授权码' 
      });
    }

    // 步骤1: 用code换取access_token
    const tokenResponse = await axios.post(
      'https://api.dingtalk.com/v1.0/oauth2/userAccessToken',
      {
        clientId: APP_KEY,
        clientSecret: APP_SECRET,
        code: code,
        grantType: 'authorization_code'
      }
    );

    const { accessToken, expireIn } = tokenResponse.data;

    // 步骤2: 用access_token获取用户信息
    const userResponse = await axios.get(
      'https://api.dingtalk.com/v1.0/contact/users/me',
      {
        headers: {
          'x-acs-dingtalk-access-token': accessToken
        }
      }
    );

    const userInfo = userResponse.data;
    
    // 步骤3: 查找或创建用户
    let user = await User.findOne({ dingtalkId: userInfo.unionId });
    
    if (!user) {
      user = await User.create({
        dingtalkId: userInfo.unionId,
        openId: userInfo.openId,
        name: userInfo.nick,
        avatar: userInfo.avatarUrl,
        mobile: userInfo.mobile,
        email: userInfo.email
      });
    } else {
      // 更新用户信息
      await user.update({
        name: userInfo.nick,
        avatar: userInfo.avatarUrl,
        lastLoginAt: new Date()
      });
    }

    // 步骤4: 生成JWT token
    const jwt = require('jsonwebtoken');
    const token = jwt.sign(
      { 
        userId: user.id, 
        dingtalkId: user.dingtalkId 
      },
      process.env.JWT_SECRET,
      { expiresIn: '7d' }
    );

    res.json({
      success: true,
      token: token,
      user: {
        id: user.id,
        name: user.name,
        avatar: user.avatar,
        email: user.email
      }
    });

  } catch (error) {
    console.error('钉钉登录失败:', error);
    res.status(500).json({
      success: false,
      message: '登录失败',
      error: error.message
    });
  }
});

module.exports = router;
```

### 3. Python (Flask) 实现示例

```python
# app/routes/auth.py
from flask import Blueprint, request, jsonify
import requests
import jwt
import datetime
from app.models import User
from app import db

auth_bp = Blueprint('auth', __name__)

APP_KEY = os.getenv('DINGTALK_APP_KEY')
APP_SECRET = os.getenv('DINGTALK_APP_SECRET')
JWT_SECRET = os.getenv('JWT_SECRET')

@auth_bp.route('/dingtalk', methods=['POST'])
def dingtalk_login():
    try:
        data = request.get_json()
        code = data.get('code')
        
        if not code:
            return jsonify({
                'success': False,
                'message': '缺少授权码'
            }), 400

        # 步骤1: 获取access_token
        token_url = 'https://api.dingtalk.com/v1.0/oauth2/userAccessToken'
        token_response = requests.post(token_url, json={
            'clientId': APP_KEY,
            'clientSecret': APP_SECRET,
            'code': code,
            'grantType': 'authorization_code'
        })
        
        token_data = token_response.json()
        access_token = token_data.get('accessToken')

        # 步骤2: 获取用户信息
        user_url = 'https://api.dingtalk.com/v1.0/contact/users/me'
        user_response = requests.get(user_url, headers={
            'x-acs-dingtalk-access-token': access_token
        })
        
        user_info = user_response.json()

        # 步骤3: 查找或创建用户
        user = User.query.filter_by(
            dingtalk_id=user_info.get('unionId')
        ).first()
        
        if not user:
            user = User(
                dingtalk_id=user_info.get('unionId'),
                open_id=user_info.get('openId'),
                name=user_info.get('nick'),
                avatar=user_info.get('avatarUrl'),
                mobile=user_info.get('mobile'),
                email=user_info.get('email')
            )
            db.session.add(user)
        else:
            user.name = user_info.get('nick')
            user.avatar = user_info.get('avatarUrl')
            user.last_login_at = datetime.datetime.now()
        
        db.session.commit()

        # 步骤4: 生成JWT
        token = jwt.encode({
            'user_id': user.id,
            'dingtalk_id': user.dingtalk_id,
            'exp': datetime.datetime.utcnow() + datetime.timedelta(days=7)
        }, JWT_SECRET, algorithm='HS256')

        return jsonify({
            'success': True,
            'token': token,
            'user': {
                'id': user.id,
                'name': user.name,
                'avatar': user.avatar,
                'email': user.email
            }
        })

    except Exception as e:
        return jsonify({
            'success': False,
            'message': '登录失败',
            'error': str(e)
        }), 500
```

## 常见问题

### 1. 获取授权码失败

**问题**: 跳转授权页后无法获取code

**解决方案**:
- ✅ 检查AppKey是否正确
- ✅ 确认回调地址已在钉钉后台配置
- ✅ 回调地址必须完全匹配(包括协议、域名、端口)
- ✅ 检查应用是否已发布

### 2. 换取access_token失败

**问题**: 使用code换取token时报错

**常见错误码**:
- `invalid_client`: AppKey或AppSecret错误
- `invalid_grant`: code已过期或已使用(code只能使用一次)
- `redirect_uri_mismatch`: 回调地址不匹配

**解决方案**:
```javascript
// 确保code只使用一次
const code = req.body.code;
if (usedCodes.has(code)) {
  return res.status(400).json({ error: 'Code已使用' });
}
usedCodes.add(code);

// code有效期5分钟,及时使用
setTimeout(() => usedCodes.delete(code), 5 * 60 * 1000);
```

### 3. 获取用户信息失败

**问题**: access_token正确但无法获取用户信息

**解决方案**:
- ✅ 检查应用权限是否开通
- ✅ 确认access_token未过期
- ✅ 使用正确的API版本(v1.0)
- ✅ 请求头格式正确: `x-acs-dingtalk-access-token`

### 4. 移动端免登失败

**问题**: 在钉钉客户端内无法免登

**解决方案**:
```javascript
// 检查是否在钉钉环境
if (dd.env.platform === 'notInDingTalk') {
  alert('请在钉钉客户端中打开');
  return;
}

// 确保corpId正确
dd.runtime.permission.requestAuthCode({
  corpId: 'your_corp_id', // 必须是正确的企业ID
  onSuccess: (result) => {
    console.log('免登成功:', result.code);
  },
  onFail: (err) => {
    console.error('免登失败:', err);
  }
});
```

### 5. 跨域问题

**问题**: 前端调用钉钉API时出现CORS错误

**解决方案**:
```javascript
// ❌ 错误: 前端直接调用钉钉API
fetch('https://api.dingtalk.com/v1.0/oauth2/userAccessToken', ...)

// ✅ 正确: 通过后端代理
fetch('/api/auth/dingtalk', ...)
```

⚠️ **重要**: 所有钉钉API调用必须在后端完成,不要在前端暴露AppSecret

### 1. 安全性

#### 保护敏感信息
```javascript
// ✅ 使用环境变量
const APP_SECRET = process.env.DINGTALK_APP_SECRET;

// ❌ 不要硬编码
const APP_SECRET = 'abc123...'; // 危险!
```

#### 验证state参数
```javascript
// 前端生成随机state
const state = Math.random().toString(36).substring(7);
sessionStorage.setItem('oauth_state', state);

// 回调时验证
const savedState = sessionStorage.getItem('oauth_state');
if (state !== savedState) {
  throw new Error('State验证失败,可能存在CSRF攻击');
}
```

#### Token安全存储
```javascript
// ✅ 使用HttpOnly Cookie (推荐)
res.cookie('token', jwtToken, {
  httpOnly: true,
  secure: true, // HTTPS

  maxAge: 7 * 24 * 60 * 60 * 1000 // 7天
});

// ⚠️ 使用localStorage (需注意XSS风险)
localStorage.setItem('token', jwtToken);
```

## 总结

钉钉授权登录的核心步骤:

1. ✅ 在钉钉开放平台创建应用,获取AppKey和AppSecret
2. ✅ 前端跳转到钉钉授权页,获取授权码(code)
3. ✅ 后端用code换取access_token
4. ✅ 用access_token获取用户信息
5. ✅ 创建或更新本地用户,生成JWT token
6. ✅ 返回token给前端,完成登录

**关键注意事项**:
- 🔐 AppSecret必须保密,只在后端使用
- ⏰ code有效期5分钟,且只能使用一次
- 🔄 access_token有效期2小时,需要刷新机制
- 🛡️ 使用state参数防止CSRF攻击
- 📝 完善的日志记录便于排查问题
