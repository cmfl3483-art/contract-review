## 项目背景

### 项目简介
- **项目名称**: 合同预审看板系统
- **技术栈**: 
  - 前端: React + TypeScript + Ant Design
  - 后端: Python FastAPI + PostgreSQL + Redis
  - 部署: Docker + Nginx
- **域名**: https://chenmin0922.online

### 为什么选择钉钉登录?

1. ✅ **企业内部应用**: 团队已使用钉钉办公,无需额外账号体系
2. ✅ **安全可靠**: 基于OAuth 2.0,由钉钉保障安全性
3. ✅ **用户体验好**: 扫码登录,无需记忆密码
4. ✅ **自动同步**: 可获取用户信息和组织架构

### 核心流程

```
用户访问系统 → 自动跳转钉钉授权页 → 扫码授权 → 
回调获取code → 后端换取token → 获取用户信息 → 
同步到数据库 → 生成JWT → 登录成功
```

## 后端实现

### 1. 核心服务类 - DingTalkAuthService

完整代码在 `backend/app/services/dingtalk_auth_service.py`:

#### 初始化配置

```python
class DingTalkAuthService:
    def __init__(self):
        self.app_key = settings.DINGTALK_APP_KEY
        self.app_secret = settings.DINGTALK_APP_SECRET
        self.redirect_uri = settings.DINGTALK_REDIRECT_URI
        self.jwt_secret = settings.SECRET_KEY
        self.jwt_algorithm = settings.ALGORITHM
        self.jwt_expire_hours = settings.ACCESS_TOKEN_EXPIRE_MINUTES // 60
```

#### 方法1: 生成授权URL

```python
def get_authorization_url(self, state: str = "default") -> str:
    """生成钉钉授权登录URL"""
    auth_url = (
        f"https://login.dingtalk.com/oauth2/auth"
        f"?client_id={self.app_key}"
        f"&response_type=code"
        f"&scope=openid"
        f"&state={state}"
        f"&redirect_uri={self.redirect_uri}"
        f"&prompt=consent"
    )
    return auth_url
```

#### 方法2: 换取Access Token

```python
async def get_access_token(self, auth_code: str) -> Dict[str, Any]:
    """使用授权码获取访问令牌"""
    url = "https://api.dingtalk.com/v1.0/oauth2/userAccessToken"
    
    payload = {
        "clientId": self.app_key,
        "clientSecret": self.app_secret,
        "code": auth_code,
        "grantType": "authorization_code"
    }
    
    async with httpx.AsyncClient() as client:
        response = await client.post(url, json=payload)
        if response.status_code != 200:
            raise Exception(f"获取access token失败: {response.text}")
        return response.json()
```

**关键点**:
- 使用 `httpx.AsyncClient` 异步请求
- code只能使用一次,有效期5分钟
- 返回的 `accessToken` 有效期2小时

#### 方法3: 获取用户信息

```python
async def get_user_info(self, access_token: str) -> Dict[str, Any]:
    """使用访问令牌获取用户信息"""
    url = "https://api.dingtalk.com/v1.0/contact/users/me"
    
    headers = {
        "x-acs-dingtalk-access-token": access_token
    }
    
    async with httpx.AsyncClient() as client:
        response = await client.get(url, headers=headers)
        if response.status_code != 200:
            raise Exception(f"获取用户信息失败: {response.text}")
        return response.json()
```

**返回的用户信息包含**:
- `unionId`: 用户在当前企业内的唯一标识
- `openId`: 用户在当前应用内的唯一标识
- `nick`: 用户昵称
- `mobile`: 手机号
- `email`: 邮箱
- `avatarUrl`: 头像URL

#### 方法4: 同步用户到数据库

```python
async def sync_user_info(
    self, 
    user_info: Dict[str, Any], 
    db: AsyncSession
) -> User:
    """
    同步钉钉用户信息到数据库
    
    身份匹配优先级:
    1. 优先按 dingtalk_union_id 匹配
    2. 回退到 dingtalk_user_id 匹配
    3. 最后才新建用户
    """
    union_id = user_info.get("unionId")
    fallback_id = union_id or user_info.get("openId")

    # 1) 优先按 union_id 匹配
    if union_id:
        stmt = select(User).where(User.dingtalk_union_id == union_id)
        result = await db.execute(stmt)
        user = result.scalar_one_or_none()
        if user:
            # 更新用户信息
            user.name = user_info.get("nick")
            user.email = user_info.get("email")
            user.mobile = user_info.get("mobile")
            user.avatar = user_info.get("avatarUrl")
            await db.commit()
            return user

    # 2) 新建用户
    user = User(
        dingtalk_user_id=fallback_id,
        dingtalk_union_id=union_id,
        name=user_info.get("nick", "未知用户"),
        email=user_info.get("email"),
        mobile=user_info.get("mobile"),
        avatar=user_info.get("avatarUrl"),
        role="业务"
    )
    db.add(user)
    await db.commit()
    await db.refresh(user)
    return user
```

#### 方法5: 生成JWT Token

```python
def generate_jwt_token(self, user: User) -> str:
    """生成JWT Token"""
    payload = {
        "user_id": str(user.id),
        "dingtalk_user_id": user.dingtalk_user_id,
        "name": user.name,
        "role": user.role,
        "exp": datetime.utcnow() + timedelta(hours=self.jwt_expire_hours),
        "iat": datetime.utcnow()
    }
    
    token = jwt.encode(
        payload, 
        self.jwt_secret, 
        algorithm=self.jwt_algorithm
    )
    return token
```

#### 方法6: 处理回调(整合所有步骤)

```python
async def handle_callback(
    self, 
    auth_code: str, 
    db: AsyncSession
) -> Dict[str, Any]:
    """处理钉钉授权回调 - 完整流程"""
    
    # 1. 获取access token
    token_data = await self.get_access_token(auth_code)
    access_token = token_data.get("accessToken")
    
    # 2. 获取用户信息
    user_info = await self.get_user_info(access_token)
    
    # 3. 同步用户信息到数据库
    user = await self.sync_user_info(user_info, db)
    
    # 4. 生成JWT Token
    jwt_token = self.generate_jwt_token(user)
    
    return {
        "token": jwt_token,
        "user": {
            "id": str(user.id),
            "name": user.name,
            "role": user.role,
            "email": user.email,
            "mobile": user.mobile,
            "avatar": user.avatar
        }
    }
```

### 2. API路由

在 `backend/app/routes/auth.py` 中定义接口:

```python
from fastapi import APIRouter, Depends
from fastapi.responses import RedirectResponse
from sqlalchemy.ext.asyncio import AsyncSession
from app.core.database import get_db
from app.services.dingtalk_auth_service import DingTalkAuthService

router = APIRouter(prefix="/api/auth/dingtalk", tags=["钉钉认证"])
dingtalk_service = DingTalkAuthService()

@router.get("/login")
async def get_login_url():
    """获取钉钉登录URL"""
    auth_url = dingtalk_service.get_authorization_url()
    return {
        "success": True,
        "data": {"authUrl": auth_url}
    }

@router.get("/callback")
async def handle_callback(
    code: str,
    state: str = "default",
    db: AsyncSession = Depends(get_db)
):
    """处理钉钉授权回调"""
    try:
        result = await dingtalk_service.handle_callback(code, db)
        
        # 重定向到前端,携带token
        frontend_url = f"https://chenmin0922.online/?token={result['token']}"
        return RedirectResponse(url=frontend_url)
        
    except Exception as e:
        # 登录失败
        error_url = f"https://chenmin0922.online/login?error={str(e)}"
        return RedirectResponse(url=error_url)
```

## 前端实现

### 1. 自动登录逻辑 (App.tsx)

在 `frontend/src/App.tsx` 中实现自动跳转登录:

```typescript
import { useEffect } from 'react';
import axios from 'axios';

const API_BASE_URL = import.meta.env.VITE_API_BASE_URL;

function App() {
  useEffect(() => {
    const checkAuth = async () => {
      // 1. 检查URL中的token参数
      const urlParams = new URLSearchParams(window.location.search);
      const token = urlParams.get('token');
      
      if (token) {
        // 保存token
        localStorage.setItem('token', token);
        // 清除URL中的token参数
        window.history.replaceState({}, '', '/');
        return;
      }
      
      // 2. 检查localStorage中的token
      const storeToken = localStorage.getItem('token');
      
      if (!storeToken) {
        // 3. 没有token,跳转到钉钉登录
        try {
          const response = await axios.get(
            `${API_BASE_URL}/api/auth/dingtalk/login`
          );
          
          if (response.data?.success && response.data?.data?.authUrl) {
            window.location.href = response.data.data.authUrl;
          }
        } catch (error) {
          console.error('获取登录URL失败:', error);
        }
      }
    };
    
    checkAuth();
  }, []);
  
  return <div>加载中...</div>;
}
```

**流程说明**:
1. 检查URL参数中是否有token(从回调返回)
2. 如果有token,保存到localStorage
3. 如果没有token,请求后端获取钉钉登录URL
4. 跳转到钉钉授权页面

### 2. Axios拦截器 (自动处理401)

在 `frontend/src/utils/axios.ts` 中配置:

```typescript
import axios from 'axios';
import { notification } from 'antd';

const API_BASE_URL = import.meta.env.VITE_API_BASE_URL;

// 创建axios实例
const axiosInstance = axios.create({
  baseURL: API_BASE_URL,
  timeout: 30000,
});

// 请求拦截器 - 自动添加token
axiosInstance.interceptors.request.use(
  (config) => {
    const token = localStorage.getItem('token');
    if (token) {
      config.headers.Authorization = `Bearer ${token}`;
    }
    return config;
  },
  (error) => Promise.reject(error)
);

// 响应拦截器 - 处理401自动跳转登录
axiosInstance.interceptors.response.use(
  (response) => response,
  async (error) => {
    if (error.response?.status === 401) {
      // 清除token
      localStorage.removeItem('token');
      
      // 提示用户
      notification.warning({
        message: '未登录或登录已过期',
        description: '即将跳转到登录页面',
        duration: 2,
      });
      
      // 跳转到钉钉登录
      setTimeout(async () => {
        try {
          const response = await axios.get(
            `${API_BASE_URL}/api/auth/dingtalk/login`
          );
          if (response.data?.success && response.data?.data?.authUrl) {
            window.location.href = response.data.data.authUrl;
          }
        } catch (err) {
          console.error('获取登录URL失败:', err);
        }
      }, 2000);
    }
    
    return Promise.reject(error);
  }
);

export default axiosInstance;
```

**关键点**:
- 请求时自动添加 `Authorization: Bearer {token}` 头
- 401错误时自动清除token并跳转登录
- 用户体验友好,有提示信息

## 踩坑记录

### 坑1: 回调地址配置错误

**问题**: 钉钉回调时报错 `redirect_uri_mismatch`

**原因**: 
- 代码中的 `redirect_uri` 与钉钉后台配置不一致
- 少了协议(http/https)或路径

**解决方案**:
```python
# ❌ 错误
DINGTALK_REDIRECT_URI=chenmin0922.online/callback

# ✅ 正确
DINGTALK_REDIRECT_URI=https://chenmin0922.online/api/auth/dingtalk/callback
```

**检查清单**:
- [ ] 协议必须一致(http/https)
- [ ] 域名必须一致
- [ ] 路径必须完全一致
- [ ] 钉钉后台已配置该地址

### 坑2: Code已使用或过期

**问题**: 使用code换取token时报错 `invalid_grant`

**原因**:
- code只能使用一次
- code有效期只有5分钟
- 用户刷新页面导致重复使用code

**解决方案**:
```python
# 在回调处理后立即重定向,避免用户刷新
@router.get("/callback")
async def handle_callback(code: str, db: AsyncSession = Depends(get_db)):
    result = await dingtalk_service.handle_callback(code, db)
    
    # 立即重定向到前端,清除URL中的code
    return RedirectResponse(
        url=f"https://chenmin0922.online/?token={result['token']}"
    )
```

### 坑3: 获取用户信息失败

**问题**: 调用 `/contact/users/me` 接口返回401

**原因**: 请求头格式错误

**解决方案**:
```python
# ❌ 错误
headers = {
    "Authorization": f"Bearer {access_token}"
}

# ✅ 正确 - 钉钉使用特殊的header
headers = {
    "x-acs-dingtalk-access-token": access_token
}
```

### 坑4: CORS跨域问题

**问题**: 前端请求后端API时报CORS错误

**原因**: 后端未配置CORS允许的域名

**解决方案**:
```python
# backend/app/main.py
```

### 坑5: Token过期后无限循环

**问题**: Token过期后,页面不断刷新

**原因**: 401拦截器跳转登录后,又因为没有token再次触发401

**解决方案**:
```typescript
// 添加防抖,避免重复跳转
let isRedirecting = false;

axiosInstance.interceptors.response.use(
  (response) => response,
  async (error) => {
    if (error.response?.status === 401 && !isRedirecting) {
      isRedirecting = true;
      localStorage.removeItem('token');
      
      // 延迟跳转,避免立即触发
      setTimeout(async () => {
        const response = await axios.get('/api/auth/dingtalk/login');
        window.location.href = response.data.data.authUrl;
      }, 2000);
    }
    return Promise.reject(error);
  }
);
```

### 坑6: 用户信息重复创建

**问题**: 同一个钉钉用户登录后创建了多个数据库记录

**原因**: 使用 `openId` 作为唯一标识,但 `openId` 在不同应用中不同

**解决方案**:
```python
# 使用 unionId 作为唯一标识(跨应用唯一)
user = await db.execute(
    select(User).where(User.dingtalk_union_id == union_id)
)
```

### 坑7: 生产环境必须HTTPS

**问题**: 生产环境使用HTTP时,钉钉拒绝回调

**原因**: 钉钉要求生产环境必须使用HTTPS

**解决方案**:
1. 申请SSL证书(Let's Encrypt免费)
2. 配置Nginx HTTPS
3. 更新钉钉后台回调地址为HTTPS

```bash
# 使用certbot申请证书
sudo certbot --nginx -d chenmin0922.online
```

### 坑8: Docker容器内网络问题

**问题**: 容器内无法访问钉钉API

**原因**: Docker网络配置问题

**解决方案**:
```yaml
# docker-compose.yml
services:
```
