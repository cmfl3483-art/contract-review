# SearchBox 组件

## 概述

SearchBox 是一个带防抖功能的搜索输入框组件,用于合同列表的实时搜索。

## 功能特性

- ✅ 实时搜索输入
- ✅ 防抖处理 (300ms)
- ✅ 清除按钮
- ✅ 搜索图标
- ✅ 自定义占位符文本
- ✅ 输入焦点效果

## Props

| 属性 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| onSearch | `(keyword: string) => void` | 是 | - | 搜索回调函数,在用户输入后300ms触发 |
| placeholder | `string` | 否 | `'搜索合同名称或发起人'` | 输入框占位符文本 |

## 使用示例

```tsx
import { SearchBox } from '@/components/ContractList';

function MyComponent() {
  const handleSearch = (keyword: string) => {
    console.log('搜索关键词:', keyword);
    // 实现搜索逻辑
  };

  return (
    <SearchBox onSearch={handleSearch} />
  );
}
```

### 自定义占位符

```tsx
<SearchBox 
  onSearch={handleSearch} 
  placeholder="搜索合同..." 
/>
```

## 实现细节

### 防抖机制

组件使用 `setTimeout` 实现防抖功能:
- 用户输入时,清除之前的定时器
- 设置新的定时器,300ms后触发搜索
- 防止频繁触发搜索,提升性能

### 清除功能

- 点击清除按钮时,立即清空输入并触发搜索(关键词为空字符串)
- 清除时会取消待执行的防抖定时器

### 内存管理

- 组件卸载时自动清理定时器,防止内存泄漏

## 样式

SearchBox 使用 Ant Design 的 Input 组件,继承其默认样式:
- 搜索图标前缀

- 焦点状态边框高亮
- 响应式宽度

## 性能优化

1. **防抖处理**: 减少搜索请求频率
2. **useCallback**: 优化回调函数引用
3. **定时器清理**: 防止内存泄漏

## 注意事项

1. 防抖延迟设置为 300ms,可根据实际需求调整
2. 清除操作会立即触发搜索,不经过防抖
3. 组件内部维护输入值状态,父组件通过 `onSearch` 回调获取搜索关键词
